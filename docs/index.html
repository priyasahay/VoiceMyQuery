What it does

🎙️ Voice Input

Speak your question directly into the browser. faster-whisper transcribes your speech offline — no cloud STT needed.

🔍 RAG Mode

Retrieves the most relevant chunks from a knowledge base using FAISS vector search, then answers with Llama 3.2 3B via Ollama.

🧠 Fine-tune Mode

Answers directly from a LoRA-adapted TinyLlama 1.1B model trained on 45 Q&A pairs. No retrieval — pure memory.

⚖️ Compare Mode

Run both pipelines on the same question and hear the answers read back sequentially to understand the difference.

🔊 Voice Output

Every answer is read aloud using macOS say (TTS). Toggle audio on/off anytime during the session.

📊 Evaluation

Built-in evaluation harness runs 15 held-out questions across in-domain, paraphrased, and out-of-scope categories.

Quick start

# 1. Clone the repo
git clone https://github.com/priyasahay/VoiceMyQuery.git
cd VoiceMyQuery

# 2. Create virtual environment and install dependencies
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 3. Start Ollama and download RAG model
ollama serve &
ollama pull llama3.2:3b

# 4. Build RAG index
python -m rag.ingest

# 5. Train LoRA adapter (optional, ~10 min on M1/M2)
python -m finetune.train_lora

# 6. Start the server
python -m server.app

# Open http://127.0.0.1:4005

       │       └── Ollama (Llama 3.2 3B) → answer

       │
       └──► TTS (macOS say) ──► audio file ──► browser
