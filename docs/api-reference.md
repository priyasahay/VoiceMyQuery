# API Reference

Base URL: `http://127.0.0.1:4005`

---

## GET /health

Returns the status of all backend components. Polled by the UI every 15 seconds.

**Response**
```json
{
  "stt_model": "base",
  "tts_engine": "say",
  "rag_llm": "llama3.2:3b",
  "ollama_up": true,
  "finetune_trained": true,
  "rag_index_built": true
}
```

| Field | Type | Description |
|---|---|---|
| `stt_model` | string | Whisper model size in use |
| `tts_engine` | string | Active TTS backend: `piper`, `say`, or `pyttsx3` |
| `rag_llm` | string | Ollama model tag |
| `ollama_up` | bool | Whether Ollama is reachable |
| `finetune_trained` | bool | Whether `adapter_config.json` exists |
| `rag_index_built` | bool | Whether `rag/index/kb.faiss` exists |

---

## POST /transcribe

Transcribes an audio file to text using faster-whisper.

**Request** — `multipart/form-data`

| Field | Type | Description |
|---|---|---|
| `audio` | file | Audio blob (webm, wav, mp3, ogg). Must be > 2000 bytes. |

**Response 200**
```json
{ "text": "What is a circuit breaker?" }
```

**Response 422**
```json
{ "text": "", "error": "recording too short — hold the mic a bit longer" }
```

---

## POST /chat

Generates a text answer using the selected mode.

**Request** — `application/json`
```json
{
  "question": "What is the difference between PUT and PATCH?",
  "mode": "rag"
}
```

| Field | Values | Description |
|---|---|---|
| `question` | string | The question to answer |
| `mode` | `"rag"` \| `"finetune"` | Which pipeline to use |

**Response 200 — RAG mode**
```json
{
  "mode": "rag",
  "answer": "PUT replaces the entire resource, while PATCH applies a partial update...",
  "sources": ["02_api_design.md"],
  "retrieved": [
    { "source": "02_api_design.md", "score": 0.51 },
    { "source": "02_api_design.md", "score": 0.44 }
  ]
}
```

**Response 200 — Fine-tune mode**
```json
{
  "mode": "finetune",
  "answer": "PUT replaces the entire resource at a given URI...",
  "sources": [],
  "retrieved": []
}
```

**Response 503 — Ollama down (RAG only)**
```json
{ "detail": "Ollama not running at http://localhost:11434. Run: ollama serve" }
```

**Response 503 — Adapter missing (fine-tune only)**
```json
{ "detail": "Fine-tuned adapter not found. Train it first (see README)." }
```

## POST /speak

Synthesises text to a WAV audio file.

**Request** — `application/json`
```json
{ "text": "REST stands for Representational State Transfer..." }
```

**Response 200** — `audio/wav` file (binary)

The response body is a raw WAV file. Use `URL.createObjectURL(blob)` in the browser to play it.

---

## POST /ask

Full voice round-trip in a single request: audio in → answer + audio out.

> Used for programmatic access. The web UI uses separate `/transcribe`, `/chat`, `/speak` calls for better streaming UX.

**Request** — `multipart/form-data`

| Field | Type | Description |
|---|---|---|
| `audio` | file | Audio blob |
| `mode` | string | `"rag"` or `"finetune"` (default: `"rag"`) |

**Response 200**
```json
{
  "transcript": "What is Kubernetes?",
  "mode": "rag",
  "answer": "Kubernetes is a container orchestration platform...",
  "sources": ["04_containers_kubernetes.md"],
  "retrieved": [...],
  "audio_url": "/audio/out_abc123.wav"
}
```

---

## GET /audio/{name}

Serves a temporary WAV file previously generated by `/speak` or `/ask`.

**Response 200** — `audio/wav`

**Response 404**
```json
{ "detail": "audio expired" }
```

## Error Codes Summary

| Code | Meaning |
|---|---|
| 200 | Success |
| 400 | Bad request (e.g. unknown mode) |
| 404 | Resource not found (audio expired) |
| 422 | Unprocessable (audio too short, transcription failed) |
| 503 | Backend unavailable (Ollama down, adapter not trained) |
